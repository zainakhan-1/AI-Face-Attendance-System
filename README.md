# AI Face-Based Attendance System

An AI-powered face recognition attendance system built with Python and OpenCV to identify registered students and record attendance automatically.

This project was developed as my **4th Semester Computer Science project at HITEC University Taxila**.

## Features

- Capture face images using a webcam
- Create a face dataset for registered users
- Train a face recognition model
- Recognize faces in real time
- Automatically record attendance
- Simple GUI for interacting with the system
- Local attendance management

## Technologies Used

- Python
- OpenCV
- Computer Vision
- NumPy
- Pillow
- Tkinter

## Installation

Clone the repository:

```bash
git clone https://github.com/zainakhan-1/AI-Face-Attendance-System.git
```

Navigate to the project directory:

```bash
cd AI-Face-Attendance-System
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

### 1. Capture Face Images

```bash
python capture_faces.py
```

### 2. Train the Recognition Model

```bash
python train_model.py
```

### 3. Run Face Recognition

```bash
python recognize_face.py
```

### 4. Launch the GUI

```bash
python gui.py
```

## Privacy

Face datasets, trained model files, attendance records, and other personal biometric information are intentionally excluded from this public repository.
